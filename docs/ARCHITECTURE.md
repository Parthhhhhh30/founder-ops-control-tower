# Architecture

Next.js App Router, React, strict TypeScript, custom Tailwind tokens, Lucide, Zod and date-fns. Client UI reads a SeedRepository implementing DataRepository; browser localStorage persists demo actions with validated restore. Fixed demo date 2026-10-06 ensures reproducible interview stories. Dates use calendar-day UTC values; no reliance on wall-clock ageing.
Domain entities and pure rule functions produce derived OperationalItems, FounderDecisions, ForwardLook and WeeklyBrief. Source records remain authoritative; no duplicated queue state. AuditEvent records accompany state mutations. DraftingProvider returns text only; its contract cannot mutate records. Mock provider works without a key.
Future SupabaseRepository uses a server-side authenticated transport with RLS; adapter seam accepts a typed backend, does not claim a live connection. LiveDraftingProvider accepts an authenticated server drafting transport and returns validated text only. No FastAPI. Vercel runs standard Next.js; local mode needs no external services.
Tests: Vitest domain and RTL interactions; Playwright desktop/responsive and critical flows. npm scripts for typecheck, lint, tests, build and smoke. Local persistence is browser-specific, synthetic, and not production authorization or a multi-user database. Future production requires Supabase account, schema/RLS, server credentials, model provider only if enabled, and deployment account. Never expose server secrets to browser.
